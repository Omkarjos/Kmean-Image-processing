# K-Means Image Compression

## Overview

This project demonstrates image compression using K-Means clustering.

Each image pixel is represented as an RGB data point. K-Means groups similar pixels into a smaller number of color clusters, reducing the number of colors while attempting to preserve visual quality.

## Objectives

- Understand K-Means clustering
- Represent RGB pixels as data points
- Reduce the number of colors in an image
- Compare original and compressed images
- Calculate reconstruction error using Mean Squared Error (MSE)
